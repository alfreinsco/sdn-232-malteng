4. Prosedur Uji Manual

  1. Siapkan database demo dan pastikan tahun ajaran/semester aktif.
  2. Uji setiap role menggunakan browser desktop dan mobile/responsive mode.
  3. Catat data awal, tindakan, hasil aktual, bukti screenshot, dan status.
  4. Untuk kasus perubahan data, kembalikan data demo setelah pengujian.
  5. Tandai Lulus jika hasil aktual sama dengan hasil yang diharapkan; selain itu buat catatan defect.
